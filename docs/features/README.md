# Elwing features

Each page shows what to ask your agent, what Elwing does with that request, and the result you get
back. Every example image was produced by the Elwing MCP server from the requests shown; run
[`generate-images.mjs`](generate-images.mjs) to regenerate them.

Before you start, [install Elwing](../../README.md#install) and
[connect your MCP client](../../README.md#connect-an-mcp-client). You talk to your agent in plain
language; it chooses the Elwing tools.

## Draw diagrams

- [Architecture diagrams](diagrams/architecture-diagrams.md): describe a system and get an AWS
  diagram with service icons, labelled relationships and groups.
- [Flow charts](diagrams/flow-charts.md): describe a process and get a top-to-bottom flow chart with
  decisions and labelled branches.
- [Edit an existing diagram](diagrams/editing-diagrams.md): add, rename, connect, regroup or
  rearrange parts of a saved diagram.
- [Badges](diagrams/badges.md): mark new or changed resources with a coloured corner label.

## Check quality

- [Readability checks](quality/readability-checks.md): find overlapping cards, vague or duplicate
  names and disconnected resources before you share a diagram.

## Share diagrams

- [Export images and files](sharing/exports.md): get SVG, PNG or an editable Excalidraw file.
- [Background colours](sharing/backgrounds.md): keep the default transparent page or choose a
  colour for slides and documents.

## Manage diagrams

- [List, find and delete diagrams](management/manage-diagrams.md): see what you have saved, find
  diagrams that use a service and clean up several at once.
