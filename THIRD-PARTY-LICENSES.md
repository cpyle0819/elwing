Generated from the engine and MCP lockfiles. Includes direct, transitive, development and optional platform packages; local project links are excluded. This is a metadata inventory, not an independent legal assessment. The build rejects missing licences and expressions outside its explicit allowlist.

The DejaVu Sans package metadata says OFL-1.1, but the shipped LICENSE contains the Bitstream Vera and Arev terms and public-domain DejaVu changes. The actual text is copied to `dist/fonts/LICENSE`; it governs the bundled font. Native resvg packages retain MPL-2.0 notices when installed. Bundled JavaScript legal comments and full installed dependency notices accompany the standalone distribution.
