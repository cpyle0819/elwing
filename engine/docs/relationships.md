# Documented relationship catalog

Generated by `node catalog-sources/document-relationships.mjs` from `catalog/relationship-rules.js`.

This curated catalog contains 461 documented relationships across 423 directed service pairs. Its 27 labels are the unique union of those relationships. It is not an exhaustive inventory of AWS integrations.

A label consolidates the operations listed beneath it. Direction represents the stated operation or configuration: a Lambda queue consumer reads from SQS; SQS handled by Lambda describes processing through a Lambda event source mapping; an SQS queue subscribes to an SNS topic, or the SNS topic is subscribed by the SQS queue. These two labels describe the same subscription in opposite directions. SNS sends to SQS describes message delivery over that subscription. A subscription arrow describes configuration, not an API request initiated by SQS. DNS routing does not proxy application traffic.

Unknown pairs have no selectable relationship until evidence is added. Missing coverage is not proof that an integration is impossible. Runtime validation checks catalog membership; it does not inspect IAM, network reachability, regions, API types, or resource configuration. Each claim records relevant scope and source evidence for review.

Saved and imported edges are preserved and marked for documentation review when unsupported. They are not part of the selectable vocabulary and are never automatically relabeled or reversed.
