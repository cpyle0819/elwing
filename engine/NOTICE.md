# Artwork and catalog notices

## AWS architecture icons

The SVG files in `catalog/icons/` come from the official AWS architecture icon package dated July 31, 2026, linked from [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/). AWS service names and artwork belong to Amazon Web Services. Consult that source for the artwork's usage terms.

Elwing has no AWS endorsement. The AWS Architecture Icons page states:

> We allow customers and partners to use these toolkits and assets to create architecture diagrams.

These artwork usage terms are separate from an open-source software licence.

`catalog-sources/import-icons.py` imports the archive into the service catalog, resource-type data, and icon directory. See [catalog maintenance](catalog-sources/README.md) for the command.

## Relationship evidence

The catalog combines curated relationships with records generated from `catalog-sources/`. Each documented claim includes its operation, conditions, review date, and primary sources. The [relationship reference](docs/relationships.md) includes those citations. Catalog labels summarize documented operations; they do not establish permissions, network reachability, regional availability, or deployed configuration.
